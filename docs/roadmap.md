# 개발 로드맵

2026-11-14: codex/stool-fomo-repro-v1의 방향을 main의 기준 계획으로 채택한다.
현재 목표는 분변 중심 검출 → 청소 영역 추정 → 실기 검증 → UI·차량 연결이다.
굳기 분류와 ToF 특징 결합은 v1 완료 조건이 아니다.

## 우선순위와 완료 기준

1. **배포 정합성:** 기준 모델 fomo_stool_v1.tflite, background/stool 라벨,
   임계값 0.60을 함께 배포. 재학습 모델은 해당 validation에서 선택한 임계값 사용.
2. **보드 검증:** strict tinyml_roi 모드로 로드, FPS/RAM/종단 지연 기록.
   PC 테스트나 모델 F1은 실제 보드 성능을 대신하지 않는다.
3. **청소 영역 검증:** 학습과 분리된 50장 이상에서 ROI-LAB 성공률 ≥90%,
   실제 영역 ≥90% 포함, 강한 음성의 잘못된 영역 선택률 ≤5% 확인.
   자세한 조건은 tinyml_roi.md를 따른다.
4. **모바일 브리지:** 실제 JPEG·검출·연결 상태 표시 및 명령/응답 연결.
   demo/live 상태를 구분하고, 연결되지 않은 상태를 실제 조작 성공으로 표시하지 않는다.
5. **차량 연결:** UART 규약 확정, 차량 워치독, 연결 해제·정지 명령 검증,
   장착 보정과 롤러 폭을 적용한 이동/영역 커버리지 구현. 그 뒤 자율 운용 평가.
6. **소변 확장:** LED 차분 실험 → 수집·음성 데이터 → 모델/영역 추정 검증 →
   기존 파이프라인 통합. 실패 조건에서만 ROI 세그멘테이션 검토.

## 현재 데이터와 평가의 범위

개발 데이터는 분변 6개 물체 집단을 포함한 195장이다.
S01–S04 학습, S05 validation, S06 test 및 물체 집단별 6-fold를 사용한다.
독립 평가는 15장으로, 초기 가이드의 세션별 70/15/15 수집 목표와 다르다.
향후에는 물체와 촬영 세션이 split을 넘지 않도록 수집 설계를 확장한다.

현재 기록은 분변 중심 검출의 초기 근거이며, ROI-LAB·시간 합의·주행·소변의
종합 정확도를 입증하지 않는다. 빈 바닥/갈색 생활용품/손/그림자/광택 바닥,
조명·거리·주행 변화 및 ROI 커버리지 검증이 남아 있다.
재현 보고서의 수치는 당시 실행 기록이며 매번 동일한 재학습 결과를 보장하지 않는다.

## 후속 선택 사항

굳기 분류(MobileNetV2 + CORAL), ToF 기반 높이 특징은 기본 파이프라인이 검증된
뒤 필요성을 결정한다. 데이터 라이선스는 아직 정해지지 않았으므로 별도 결정이 필요하다.
